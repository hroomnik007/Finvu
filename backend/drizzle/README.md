# Frozen legacy schema

These SQL files are the original schema, generated by drizzle-kit. They are **not used in
production anymore** and must not be extended: new database changes go to
`backend/migrations/` (numbered SQL files, applied by `npm run db:migrate`).

On an empty database `npm run db:setup` applies these files first (`src/scripts/baseline.ts`)
and then all migrations. `src/db/schema.ts` stays the typed view of the schema for the code.
